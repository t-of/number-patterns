# 数の模様 — つまみで変わる数学の模様

素数のらせん・星形・マンデルブロ集合など、数と円が描く模様を切り替えて眺める。つまみで数を変えると、模様がその場で形を変える。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/number-patterns/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 下の図の名前をタップすると、その模様を描き始める（約 3 秒かけて描く）。
2. つまみを動かすと、模様がその場で変わる。「おまかせ」で、でたらめな値を試せる。
3. 図をタップすると、もう一度はじめから描く（マンデルブロ集合は、タップした所を中心に 3 倍に拡大する。「全体に戻す」で最初の範囲へ）。

図は 8 つ: 素数の模様・倍数の模様・コラッツの道・星形・マンデルブロ集合・コッホ曲線・円運動の合成・円上の 2 点。

- 「−」「＋」は 1 ずつ。押しっぱなしで続けて変わる。
- PC では ← → で図を切り替え、R でもう一度描く。
- 共有すると、今の図と値が URL（`?f=star&p=7,3` など）に入る。その URL を開くと同じ模様で始まる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも使えます。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

テスト（Node.js、フレームワークなし）:

```sh
node test.mjs
```

| ファイル | 中身 |
|---|---|
| `patterns.js` | 中身（素数のふるい・うずまき・コラッツ・星形・マンデルブロの発散・コッホ曲線・円運動の周期、つまみの範囲、保存と URL の読み書き、値の要約）。DOM に触らない |
| `main.js` | 画面と操作・描画・音 |
| `test.mjs` | `patterns.js` のテスト |

- 図ごとの描き方は「描く物の数」と「from〜to 番目を描く」の組（main.js の `PLANS`）。描く様子はこれを時間で割って少しずつ描く。
- マンデルブロ集合は 1 CSS px に 1 点で計算し、1 フレーム 10ms までに区切って描く。スライダーを動かしている間は 2×2 に 1 点の粗い絵だけ出す。
- Canvas は 3 倍の画面でも 2 倍の解像度で描く（描く量を抑える）。
- 保存は `number-patterns.state`（`{ v: 1, fig, p: { 図: [値…] }, sound, seenHelp }`）。触った図の値だけ入れる。マンデルブロ集合の拡大の位置は保存しない（共有の URL には入れる）。
- 元は Processing の小品（自作）。元にあった誤り（素数の判定が √n 未満まで、星形の角度が整数、マンデルブロの判定が |a + b| > 16）は直してある。
